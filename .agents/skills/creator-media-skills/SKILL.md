# 自媒体必备工作流（七段）

覆盖：拆选题 → 找对标 → 写稿 → 起标题 → 配图 → 去 AI 味 → 归档（文档/飞书等）。

## Inputs
- 账号定位与平台
- 本周主题或对标账号
- 品牌语气

## Outputs
- 选题池与对标拆解表
- 成稿 + 标题 10 选 3
- 配图/封面提示
- 归档条目（可检索字段）

## Steps
1. **拆选题**：平台热词 × 账号支柱 → 选题卡（钩子/角度/证据）。
2. **找对标**：结构、标题公式、互动钩子；只学结构不抄内容。
3. **写稿**：按平台篇幅；先大纲后正文。
4. **标题**：10 条 → 人工选 3；标风险（夸张/违规）。
5. **配图**：封面文案 ≤6–8 字；风格锁。
6. **去 AI 味**：跑去套话检查。
7. **归档**：题目、链接、数据、可复用段落进知识库。

## Automation map
- 可自动：对标摘要、初稿、标题发散、配图提示、归档草稿
- 须人工：最终选题、合规、封面定稿

## Checklist
- [ ] 有对标结构笔记
- [ ] 标题有风险标记
- [ ] 成稿已归档可检索
