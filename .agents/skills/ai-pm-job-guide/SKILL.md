# AI 产品经理求职通关

帮候选人过三道关：简历、投递、面试；并检验是否具备真实 AI 产品判断力（而不只是会背术语）。

## Inputs
- 目标 JD（或岗位族）
- 当前简历 / 项目经历
- 可选：目标公司类型（大厂/创业/ToB）

## Outputs
- JD 差距表（必须/加分/缺失证据）
- 改写后的量化成果句（STAR + 指标）
- 投递材料包（简历要点、邮件/打招呼、作品集索引）
- 模拟面试记录 + 评分表 + 改进待办

## Steps
1. **解析 JD**：拆成问题定义、用户/场景、成功指标、技术约束、协作面。
2. **差距分析**：对每条要求标 有证据 / 可迁移 / 缺口；缺口写「如何 2 周内补证据」。
3. **改简历**：每条经历改成「场景–动作–指标–影响」；删空话；AI 经历必须写清：目标用户、基线、方案取舍、评测、上线结果。
4. **判断力探针**（必问自己）：
   - 为何不用更简单方案？
   - 评测集怎么建？幻觉/延迟/成本如何权衡？
   - 失败时产品侧如何降级？
5. **投递**：按岗位族切换模板（AI 应用 PM / Agent 平台 / 数据产品）；一岗一信，突出匹配点。
6. **模拟面试**：扮演面试官 3 轮追问（产品设计→技术协作→落地与指标）；给 1–5 分评分表。
7. **沉淀**：把该岗位族的提示与范文存成可复用模板。

## Checklist
- [ ] 简历每条有可量化结果或明确基线
- [ ] 至少一个项目能讲清评测与取舍
- [ ] 模拟面试有书面改进待办
